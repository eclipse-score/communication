# Engineering documentation

`dependability-workflow.md` is a human-maintained explanation and historical design
rationale. It is not a routine agent input or a knowledge depot.

Do not modify that document unless the human explicitly requests authoring or
revising it. Routine feature work, depot consolidation, tooling upgrades, or changes
to skills do not authorize updating it. When explicitly asked to change the workflow,
it may be read for background, but its potentially obsolete statements must be
checked against current skills and sources.

The other knowledge depots remain editable by humans and agents under the active
workflow. This restriction is specific to the rationale document.
