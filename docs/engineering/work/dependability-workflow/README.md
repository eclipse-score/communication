# Dependability workflow and knowledge depots

Objective: establish scoped current knowledge, disposable feature work, and
human-gated cycles for local dependability work.

Boundary: local workflow skills, routing prompt, knowledge depots, feature handoffs,
and the requested human rationale. No product-code, TRLC, PlantUML, BUILD, upstream
tooling, or copied `score-*` skill changes. Legacy research remains available.

Current cycle: [Workflow and initial depots](cycles/01-workflow-and-depots.md).

Completion requires review of the authored workflow and extraction, validation of
the package, and an explicit disposition for any further migration work. Creating
this package does not authorize removing legacy research or resuming safety analysis.
