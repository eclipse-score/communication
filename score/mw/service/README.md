# mw/service

This part of our code shall give guidance and common code on how to interact with service instances provided by a
middleware implementation (`mw::com` or ...).

The example application as well as the provided unit tests in this component shall serve as blueprint and golden sample
on how to correctly use and unit test code which makes use of `mw::service`.

## Design

The detailed designs of this component are located in [design](./design) and also documented in [design/README.md](./design/README.md).
